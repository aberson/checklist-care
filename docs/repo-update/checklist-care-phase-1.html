What you can do now

Turn a YouTube video into tips

/checklist-ingest https://www.youtube.com/watch?v=LpeDuC2sQ-w

Run it in Claude Code inside the checkout, or ask Codex to use the checklist-ingest skill (launch line in AGENTS.md ## Codex usage). Chapter titles become tip names.

Ingest pasted text or a text file

/checklist-ingest <full path of a .txt file>

Or paste the text after the command. Useful for articles and pages that are not on Wikipedia.

Investigate a book from its Wikipedia page

/checklist-ingest https://en.wikipedia.org/wiki/The_Happiness_Hypothesis

The skill reads the article, then searches the web for the book's advice. Each tip carries an evidence URL. Without web search it runs in a marked degraded mode.

Review and approve proposals

uv run checklist-care serve --build

Open http://127.0.0.1:8450/#/review. Approve, edit, re-bucket or mark "Left out". Nothing prints until you approve it.

Shape your library, rubrics and lists

#/library · #/buckets · #/lists

Add your own basics ("Brush your teeth"), edit each bucket's rubric, and manage room lists with their cues. The skill reads the rubrics and cues on every ingest.

Print A4 sheets

Lists → Coffee Machine — Adults → Print

One sheet per room and audience, plus a "Good to do now and then" activities sheet. Print at 100% with browser headers and footers off.

Score the skill against labels

uv run checklist-care --data-dir "<eval dir>" eval score --labels eval/labels/in_sample.json

Grades the database rows the skill stored, never a transcript. Exit 0 PASS, 1 a hard criterion failed, 6 the input cannot give a verdict.

Back up your data

uv run checklist-care backup

Writes a consistent copy of the database under %LOCALAPPDATA%\checklist-care\backups\. Your data never enters the repo.

Built and gated, not yet accepted by you. The live checks (uv run pytest -m live, scripts/smoke.py --live), both hosts' in-sample and out-of-sample runs, the book investigation and a real A4 print are manual steps M1–M6 in the plan.

How the pieces fit

The skill only judges; tested code does every fetch, check and database write. A bad proposal is rejected field by field and nothing is stored.
